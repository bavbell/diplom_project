# Дипломный проект: Анализ поведения пользователей мобильной игры «3 в ряд»

## Описание проекта

Данный проект выполнен в рамках дипломной работы по курсу «Продуктовый аналитик в IT».  
Цель работы — провести анализ поведения пользователей мобильной игры в жанре «3 в ряд», выявить ключевые проблемы удержания и онбординга, а также предложить рекомендации по улучшению продукта.

## Используемые технологии

- **ClickHouse** — хранение и обработка сырых данных
- **DBeaver** — работа с SQL-запросами
- **Tableau Public** — визуализация дашбордов и воронок
- **Python (pandas, scipy, statsmodels)** — проведение A/B-теста и статистический анализ

## Структура репозитория

- `Script_diplom.sql` — основной SQL-скрипт (создание таблиц, очистка, расчёт метрик)
- `DDL_user_*.sql` — скрипты для создания таблиц `user_info`, `user_session`, `user_payments`
- `ab_test.ipynb` — Jupyter Notebook с A/B-тестом нового тутора
- `*twb` / `*.csv` — файлы для Tableau (дашборды, выгрузки)
- `diplom_project.pdf` — итоговая презентация проекта

## Основные результаты

- До финиша тутора доходит **42,8%** игроков  
- Основная просадка в воронке — **на шаге 5** 
- **Day 1 Retention** — около **10%**, **Day 3–14 Retention — 0%**  
- **A/B-тест** нового тутора не показал статистически значимых различий (p = 0,389)  
- Рекомендовано: сократить тутор, упростить сложные шаги, ввести ежедневные бонусы
